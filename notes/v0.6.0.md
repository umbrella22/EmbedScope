EmbedScope 0.6.0 shares the `rs_lvgl_sys` 0.8 native provider with applications
using `rs_lvgl` or `rs_lvgl_ui` 0.8. The wire protocol remains v1 and the C ABI
is unchanged.

[Documentation](https://umbrella22.github.io/EmbedScope_website/)

## Inspector

- The Properties panel shows application-reported input outcomes and preview
  evidence in English and Simplified Chinese. It distinguishes a received
  action, a confirmed UI value and a matching completed frame. Missing or
  unconfirmed results remain visible.
- The device supplies the `escope.ui.evidence.v1` records. Devices that omit
  those records continue to provide their existing tree, logs and captures.

## Native integration

- The Rust consumer exercises tree revision, native geometry, pointer input,
  framebuffer refresh, controlled forms, charts and custom widgets using LVGL
  9.6 with the registry `rs_lvgl_sys` 0.8.0 provider.
- The standalone [C/LVGL example](https://github.com/umbrella22/EmbedScope/tree/v0.6.0/examples/c-lvgl)
  exposes a live LVGL object tree and logs through the C SDK. The C application
  builds its existing LVGL provider and serves the Agent through a host
  loopback transport.

| EmbedScope native SDK | Shared `rs_lvgl_sys` provider |
| --- | --- |
| 0.1.x | 0.3.x |
| 0.2.x | 0.4.x |
| 0.3.x | 0.5.x |
| 0.4.x | 0.6.x |
| 0.5.x | 0.7.x |
| 0.6.x | 0.8.x |

Update the native SDK and the application's LVGL provider together. Apps with
their own `TreeSource` can use the default `escope-lvgl` feature set, which has
no LVGL dependency. The Rust and C/LVGL reference checks run on host memory
displays. The ESP32-S31 Dango OS brightness and reconnect run used EmbedScope
0.2 and an application-provided `TreeSource`.

## Downloads

| Platform | Inspector | CLI |
| --- | --- | --- |
| macOS Apple Silicon | `embedscope-inspector-0.6.0-aarch64-apple-darwin.zip` | `escope-0.6.0-aarch64-apple-darwin.zip` |
| macOS Intel | `embedscope-inspector-0.6.0-x86_64-apple-darwin.zip` | `escope-0.6.0-x86_64-apple-darwin.zip` |
| Linux x64 | `embedscope-inspector-0.6.0-x86_64-unknown-linux-gnu.AppImage` | `escope-0.6.0-x86_64-unknown-linux-gnu.zip` |
| Windows x64 | `embedscope-inspector-0.6.0-x86_64-pc-windows-msvc.zip` | `escope-0.6.0-x86_64-pc-windows-msvc.zip` |

- **Inspector** — Open the extracted macOS or Windows app. On Linux, run
  `chmod +x` on the AppImage before launching. macOS builds use ad hoc signing.
- **CLI** — Extract and run `escope --help` (`escope.exe` on Windows). Rust users
  can also run `cargo install escope-cli --version '=0.6.0' --locked`.
- **C/C++ SDK** — `embedscope-c-sdk-0.6.0.zip` includes the C header, device SDK
  sources, lockfile and static-library wrapper.

`SHA256SUMS` covers the nine distribution archives. The five SDK libraries and
`escope-cli` are also distributed on crates.io.
