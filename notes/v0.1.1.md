EmbedScope provides a native Inspector, the `escope` command-line tool, and
embedded SDKs for device logs, metrics, UI inspection, display capture and input.

[Documentation](https://umbrella22.github.io/EmbedScope_website/)

## Downloads

| Platform | Inspector | CLI |
| --- | --- | --- |
| macOS Apple Silicon | `embedscope-inspector-0.1.1-aarch64-apple-darwin.zip` | `escope-0.1.1-aarch64-apple-darwin.zip` |
| macOS Intel | `embedscope-inspector-0.1.1-x86_64-apple-darwin.zip` | `escope-0.1.1-x86_64-apple-darwin.zip` |
| Linux x64 | `embedscope-inspector-0.1.1-x86_64-unknown-linux-gnu.AppImage` | `escope-0.1.1-x86_64-unknown-linux-gnu.zip` |
| Windows x64 | `embedscope-inspector-0.1.1-x86_64-pc-windows-msvc.zip` | `escope-0.1.1-x86_64-pc-windows-msvc.zip` |

- **Inspector:** extract the macOS or Windows ZIP and launch the application.
  On Linux, make the AppImage executable with `chmod +x` and run it.
- **CLI:** extract the ZIP and run `escope --help` (`escope.exe` on Windows).
  Add its directory to `PATH` to run it from any terminal. Rust is not required.
- **C/C++ SDK:** `embedscope-c-sdk-0.1.1.zip` contains `include/escope.h`, device
  SDK sources, a lockfile and a static-library wrapper. Build it for the firmware
  target with the matching Rust toolchain, then link the generated library.
- **Rust SDKs:** `escope-protocol`, `escope-agent`, `escope-lvgl`, `escope-c-api`
  and `escope-host` are available on crates.io. For users with Rust installed,
  `cargo install escope-cli --version '=0.1.1' --locked` is an optional CLI setup.

`SHA256SUMS` covers all attached packages. macOS bundles have ad hoc signatures
and are not notarized; macOS may require approval in Privacy & Security. Linux
requires glibc 2.35 or newer and a desktop OpenGL driver for Inspector; the CLI
uses the system `libudev`. AppImage extraction is available on systems without
FUSE. Windows executables use the static MSVC runtime.

## Changes

- Portable Inspector packages for macOS and Windows, and an AppImage for Linux.
- ZIP distributions for the CLI on all supported platforms and the C/C++ SDK.
- English and Simplified Chinese Inspector UI, with persistent language choice.
- Optional dangoOS and rs_lvgl integrations, including explicit build switches
  for enabling diagnostics during development and omitting them for delivery.
- Updated installation guides, integration/debug skills, and documentation logo.
- Standard macOS serial rates use termios to avoid a blocking USB CDC speed ioctl.

The release workflow validates source packages, standalone Rust/C consumers,
native CLI sessions and launches of the packaged Inspector before publication.
